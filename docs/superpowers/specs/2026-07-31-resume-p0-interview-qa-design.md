# 新版简历 P0 面试题与回答设计

## 目标

基于 `简历相关/resume_zhaisifeng.md` 新建一份精简 P0 面试题库，帮助候选人在面试中准确说明个人定位、项目职责、技术方案、业务结果和能力边界。

## 输出文件

`简历相关/question/新版简历P0面试题与回答.md`

## 内容范围

共整理 20 道必问题：

1. 个人定位与职责边界：3 题。
2. Reolink SSR、BFF 与商城后台：7 题。
3. GogoalShop 性能优化与 Next.js：4 题。
4. Shopify 自研应用：2 题。
5. 喜动商城 Go 后端、交易链路与 AI：4 题。

不重复收录 React、HTTP、Webpack 等通用八股题，这些内容继续由现有 `简历相关/question/面试.md` 承载。

## 单题结构

每道题包含：

1. 面试官考察点。
2. 60～90 秒推荐回答。
3. 二次追问要点。
4. 回答边界。

## 回答原则

- 使用“结论 -> 场景 -> 方案 -> 结果 -> 边界”的表达结构。
- 只使用当前简历已有事实与指标，不增加无法验证的数据。
- Reolink 定位为 React 前端主责，并承担 Node.js SSR、BFF 编排和商城后台交付。
- Reolink BFF 不拥有核心订单、售后领域数据，不描述为直接维护核心交易数据库。
- Go、MySQL、事务、库存一致性等后端深度由喜动商城个人项目承接。
- 明确个人主导、个人参与和团队结果，避免将团队产出全部表述为个人产出。

## 验收标准

- 恰好包含 20 道 P0 问题。
- 覆盖当前简历四个项目及个人定位。
- 不出现 React Native 经历或旧版移动端项目口径。
- Reolink 与喜动商城的服务端职责边界一致。
- 简历中的关键指标、技术栈和项目时间无冲突。
- Markdown 格式检查通过。

## 测试影响

本次仅新增面试准备文档，不涉及业务逻辑、数据流或用户交互，单元测试与 E2E 测试不适用。通过内容核对、关键词扫描和 Markdown 格式检查完成验证。
